# CAP-Learning-Beginner-MusicLib
> A Beginners friendly CAP project

## Pre-Requsits
Make sure the following the instructions [here](https://cap.cloud.sap/docs/get-started/#getting-started).


## Get Started
- Clone from the Git repo
`git clone https://github.tools.sap/Blue-Ocean/CAP-Learning-Beginner-MusicLib.git`
- Install dependencies
`npm install`
- Start the project
`npm start`
- Refer to the API Docs [here](../test/http/MusicLibrary.http)
 You can make all HTTP requests within VS Code.
